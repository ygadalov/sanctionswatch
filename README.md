# SanctionsWatch

Агрегатор санкционных списков (US OFAC · UK UKSL · EU FSF + суда ст. 3s · UN SC · CA GAC · CH SECO · AU DFAT · JP MOF) с интерактивным дашбордом (карта мира, сквозные фильтры), фаззи-скринингом контрагентов и журналом изменений.

Предложения по развитию проекта собраны в [ROADMAP.md](ROADMAP.md).

## UX

- **Сквозные фильтры**: клик по карте, столбцу диаграммы, строке источника, типу сущности или программе фильтрует весь дашборд; активные фильтры отображаются чипами, сброс — крестиком или «Сбросить всё». Фильтры источника/типа прокидываются в скрининг.
- **Карта мира**: хорометрия по числу субъектов на страну (логарифмическая шкала), тултип при наведении, клик — фильтр. Страна = гражданство/регистрация субъекта, не страна-инициатор санкций.
- **Темы**: светлая (по умолчанию, «банковская») и тёмная (терминал), переключатель в шапке, выбор сохраняется.
- Двуязычие RU/EN.

## Как читать цифры

- **Записи в списках** — каждое включение субъекта в каждый список считается отдельно.
- **Уникальные субъекты** — оценка после дедупликации по имени и дате рождения между списками.
- Медийные счётчики («20 000+ санкций против РФ») дополнительно включают секторальные меры и 30+ юрисдикций — это другая методология.

## Структура

```
index.html / styles.css / app.js   — статичный фронтенд (GitHub Pages)
fonts.css / favicon.svg            — шрифты и иконка
data/stats.json                    — агрегированная статистика
data/entities/all.json           — полный срез записей (клиент грузит один раз)
data/countries.geo.json          — геометрия стран для карты (Natural Earth 110m, генерируется пайплайном)
data/health.json                   — журнал здоровья источников (ok/stale/failed)
data/changelog.jsonl             — журнал добавлений/удалений (аудит-трейл)
data/raw/                          — сырые файлы источников (кеш, в git не коммитить)
pipeline/build_data.py             — парсер-нормализатор (stdlib only)
.github/workflows/update-data.yml  — автообновление ежедневно ночью по Москве (00:30 UTC)
```

## Развёртывание

1. Запушьте репозиторий на GitHub.
2. Settings → Pages → Source: `GitHub Actions` (или ветка `main`, root).
3. Actions → включите workflows; первый запуск можно стартовать вручную (`workflow_dispatch`).

Локальный прогон пайплайна:

```bash
REFRESH=1 python3 pipeline/build_data.py   # принудительное скачивание
python3 pipeline/build_data.py             # использовать кеш data/raw
```

## Источники

| Код | Список | Доступ |
|---|---|---|
| US | OFAC SDN | официальный API, XML |
| UK | UK Sanctions List (FCDO) | статичный URL, XML |
| EU | Consolidated FSF (DG FISMA) | публичный токен, XML |
| EUMARE | EU Designated Vessels — ст. 3s Регл. 833/2014 (Annex XLII/IV, «теневой флот»: запрет захода в порты и морские услуги, НЕ заморозка активов) | через OpenSanctions EU Journal (транскрипция аннексов EUR-Lex) |
| UN | SC Consolidated List | XML |
| AU | DFAT Consolidated List | через OpenSanctions (официальный — XLSX) |
| JP | MOF Economic Sanctions | через OpenSanctions (официальный — XLSX, японский) |
| CA | Canadian Consolidated Autonomous Sanctions | через OpenSanctions (Global Affairs Canada) |
| CH | SECO Sanctions/Embargoes | через OpenSanctions (SECO) |

## Дисклеймер

Инструмент поддерживает решения комплаенс-офицера, но не заменяет его. Совпадение по имени требует верификации вторым идентификатором. Для юридически значимых проверок сверяйтесь с первоисточником.
